# Backend-Ledger-Banking-System
A high-concurrency core banking backend featuring double-entry ledger accounting, atomic fund transfers, and ACID-compliant transaction processing.

## API documentation

Start the server with `npm run dev` or `npm start`, then open
`http://localhost:3000/api-docs` for the interactive Swagger UI. It documents
the authentication, account, and transaction endpoints. Protected endpoints
use the `token` cookie set by registration and login.
